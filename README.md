# 📈 NovaTrade - Real Time Trading Broker

NovaTrade es una plataforma web de trading desarrollada con React que permite visualizar gráficos financieros en tiempo real, monitorear múltiples divisas y simular operaciones binarias mediante una interfaz moderna e interactiva.

---

## 🚀 Características Principales

* 📊 Gráficos de velas japonesas (Candlestick Charts)
* 🔄 Datos financieros consumidos desde una API en tiempo real
* 💱 Monitoreo de múltiples divisas:

  * EUR/USD
  * CAD
  * MXN
  * BRL
  * AUD
  * Y más
* ⏱️ Sistema de expiración configurable
* 💵 Simulación de inversiones
* 📈 Operaciones:

  * SUBIR
  * BAJAR
* 📜 Historial de operaciones
* ⚙️ Panel de configuración
* 🌙 Diseño moderno estilo broker profesional
* 📱 Responsive Design

---

## 🛠️ Tecnologías Utilizadas

## ▶️ Instalación y Ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/novatrade.git
```

2. Entrar al proyecto:

```bash
cd RetoApi
```

3. Instalar dependencias:

```bash
npm install
```

4. Ejecutar el proyecto:

```bash
npm run dev
```

5. Abrir en el navegador:

```bash
http://localhost:5173
```
